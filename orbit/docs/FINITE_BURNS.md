# Mode B: 전체 임무 평가와 유한 연소

종단 상태 수렴만으로 통과하지 않는다. [종말 하강·접촉 제약](TERMINAL_DESCENT.md)을 전체 하강 표본에서 만족해야 한다. [새 기본 예제](SUCCESSFUL_DEFAULT.md)는 기존 제한을 통과한 입력으로 교체됐다.


기존 LLO와 Mode A는 유지한다. Mode B는 여러 착륙 후보의 전이와 하강 비용을 함께 평가하고 NRHO 이탈·LLO 진입·DOI를 실제 유한 연소로 적분한다. 모든 런타임 계산은 TypeScript Web Worker와 정적 NASA 파일만 사용한다.

## 추진 모델

각 연소의 추력 크기는 사용자가 지정한 최대 추력이고 방향은 연소 중 고정된 달 중심 J2000 벡터다.

```text
dr/dt = v
dv/dt = a_selected_lunar_gravity(r,t) + a_Earth/Sun_relative(r,t) + F/m
dm/dt = -|F|/(Isp*g0), g0 = 9.80665 m/s²
```

질량유량과 비추력 관계는 [NASA Glenn 설명](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/specific-impulse/)을 따른다. 진공 추력·비추력은 일정하며 질량 감소에 따라 가속도가 증가한다. 특성 ΔV는 `∫|F|/m dt`로, 중력을 포함한 실제 속도 벡터의 전후 차이와 다르다. 연소 시간은 `m0*(1-exp(-ΔV/(Isp*g0)))*Isp*g0/T`이고 위치·속도·질량은 운동방정식으로 계산한다.

출발 시각은 이탈 연소 시작, LLO 도착 시각은 진입 연소 종료다. 두 연소와 중간 coast를 전이 시간 안에 배치한다. DOI는 기존 설계 시각에 점화하고 실제 종료 뒤 남은 구간을 PDI까지 적분한다. 연소 중첩, 추력 범위 위반, 연료 부족은 성공 결과를 만들지 않는다.

## 전이 재표적화와 연속성

Lambert·충격기동 해는 초기 추정이다. 이탈·진입 연소 벡터의 6개 성분을 조절해 실제 유한 연소 종료 위치 3성분과 속도 3성분을 목표 LLO 상태에 맞춘다. 긴 coast는 같은 중력 모델의 상태 천이행렬로 미분하고, 연소 시간 변경에 따른 시작·종료 시각 항을 포함한다. 짧은 연소는 질량과 지속시간 변화를 포함한 중심 차분으로 미분한다.

최종 경로는 더 엄격하게 재적분한다. 목표로 상태를 리셋하거나 속도·질량을 순간 변경하지 않는다. 실제 진입 상태와 질량에서 DOI·하강을 다시 계산한다.

- 전이 위치 잔차 ≤0.05 m, 속도 잔차 ≤1e-5 m/s.
- 정밀화 차이 ≤0.05 m 및 ≤1e-5 m/s, 질량 회계 차이 <1e-6 kg.
- 전이 충돌 경계는 달 기준 반지름+12 km이며 적응 적분의 표본 검사다.
- DOI는 RK4 0.25초 이하로 재생하고 같은 힘·시간을 별도 DOPRI 0.125초 이하로 확인한다.
- 기존 하강 24개 가속도 명령 구간, 질량·추력·지형 검사와 단계별 선택 중력의 일관성을 유지한다.

## 전체 임무 탐색

시간·접근 방향 미지정 시 최대 48개 착륙 후보를 생성한다. 새 기본 예제는 880초·180°와 세 위상 초기값을 사용하며, 전이 전에 종말 조건으로 선별한다. 하강 연료가 가장 적은 하나를 먼저 확정하지 않는다. 각 후보의 전이 연소와 실제 도착 질량을 계산하고 DOI·하강을 이어 검증한 완성 경로만 비교한다.

접근 방향을 번갈아 검사한다. 먼저 전이 시간 범위의 처음·중간·끝을 여러 착륙 후보에 평가하고, 여유가 있으면 9점 격자의 나머지 6개 시각과 보관한 다른 전이 초기 해를 평가한다. 한 후보의 미수렴으로 다른 후보 탐색을 중단하지 않는다.

| 목표 | 전체 임무 점수 |
|---|---|
| 총 ΔV | 이탈+진입+DOI+동력 하강의 특성 ΔV 합 |
| 전체 시간 | 이탈 점화부터 접지까지의 시간 |
| 균형 | 전체 ΔV + 전체 비행 1일당 100 m/s |

동점이면 전체 추진제와 시간을 비교한다. 공통인 이탈 전 3시간 참조 coast는 목적함수에서 제외한다. 하강 패널의 연료/시간 설정은 초기 후보 순서에만 영향을 준다.

`joint_search`에 시간 격자, 선별 후보 수, 유한 연소 시도·통과 수, 후보별 비용과 실패 원인, 선택 후보와 탐색 완료 여부를 기록한다. 예산 종료 시 이미 검증된 후보 중 최선만 반환한다. 통과 경로가 없으면 빈 궤적과 실패 진단을 반환한다. 전역 최적성이나 물리적 불가능의 증명이 아니다. 초기점은 충격기동의 ΔV·충돌·수렴 선별을 통과한 해에 한정되므로 다른 유한 연소 해를 놓칠 수 있다.

## 질량과 출력

`llo`는 진입 연소 종료 질량을 고정하고 필요한 NRHO 출발 질량을 계산한다. `nrho`는 출발 질량을 고정하고 실제 도착 질량으로 하강을 다시 계산한다. 탱크 용량과 최대 습윤 질량은 별도 모델링하지 않는다.

`finite_burns`에는 추력 벡터(N), 실제 시작·종료 상태, 지속시간과 추진제량을 내보낸다. 그 시각과 이벤트·제어 시각은 전체 표시 임무 시작 기준이다. 내부 `transfer_diagnostic`은 정적 천체력 ET offset을 사용한다. 화면은 적분된 `DEPARTURE_BURN`, `INSERTION_BURN`, `DOI_BURN` 구간과 연소 시간을 표시한다.

## 검증과 한계

[검증 결과](FINITE_BURN_VALIDATION.md)는 해석적 상수 추력 검사, 알려진 유한 연소 전이 재표적화, 두 질량 기준, 실패·연속성 검사, 기존 Mode A/LLO 회귀, 직접 SPICE·독립 SciPy DOP853 재생을 다룬다. Python은 개발 검증에만 사용한다.

고정 관성 방향·최대 추력 연소라는 제한은 남는다. 자세·짐벌·선회율, 점화 과도응답, 항법·엔진 불확실성, 조명·통신·전력, 착륙장치·지반, 고해상도 장애물은 모델링하지 않는다. 독립 재적분도 전체 LOLA 경로를 독립 감사하지 않으며 실제 운용 인증이 아니다.
