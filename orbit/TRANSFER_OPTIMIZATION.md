# NRHO → LLO 전이 계산 및 검증

`frontend/src/physics/nrho/transfer.ts`는 브라우저에서 실행되는 **2충격기동 CR3BP 전이**를 계산합니다. 연결 목표는 고도만으로 정의하지 않고, 기존 착륙 엔진이 계산한 LLO의 정확한 위치·속도·궤도면·위상입니다. Mode A 상대시간에서 전이 도착을 `t=0`으로 두며, 통합 임무가 이를 공통 시간축으로 옮깁니다.

## 입력과 출력

입력 `TransferOptions`에는 JPL 기준 초기상태와 LU/TU/μ, 도착 목표 `target_state_nd`, 출발 위상 후보, 비행 시간 범위, 총 전이 ΔV 한계, 최대 shooting 반복 수, 계산 시간 예산, 선택 목적과 위치 허용오차가 들어갑니다. 모든 상태는 동일한 정규화된 지구–달 질량중심 회전좌표계입니다.

성공 결과는 출발 전/후 상태, 진입 전 실제 적분 상태, 두 ΔV 벡터, 상대 시간별 실제 CR3BP 상태, 후보별 실패 원인 및 수치 검사 결과를 포함합니다. 표시용 곡선으로 연결하거나 최종 위치를 목표점으로 덮어쓰지 않습니다. LLOI는 실제 진입 전 속도와 목표 속도의 차이로 계산합니다.

## 초기 추정과 differential shooting

1. 각 출발 위상까지 JPL 기준 상태를 실제 CR3BP로 전파합니다. 기본은 한 주기를 12개 위상으로 나누지만 사용자가 수동 위상을 지정할 수 있습니다.
2. 기본 비행 시간 범위 0.3–3일에서 균등하게 5개 값을 시험합니다. 각 위상·시간 조합에 짧은/긴 각도의 0회전 Lambert 초기 추정 두 개를 사용하여 총 120개 후보를 구성합니다.
3. Lambert 계산은 달 중심 2체의 초기 속도 **추정값만** 제공합니다. 도착 위치를 출발 시점의 관성축으로 회전하고, 추정 속도에서 `ω×r`을 빼 회전좌표계로 돌립니다. Lambert 궤적은 결과나 애니메이션으로 사용하지 않습니다.
4. CR3BP 상태와 6×6 상태 천이행렬을 전방 적분합니다. 목표 위치 잔차 3성분과 최종 위치의 초기 속도 민감도 3×3 블록으로 초기 속도를 Newton 보정합니다. 잔차는 모두 같은 무차원 길이 단위이며 속도 잔차와 섞어 합산하지 않습니다.
5. 제한된 보정량과 단계 길이 탐색으로 위치 잔차가 줄어드는 보정을 채택합니다. 위치가 수렴하면 진입 속도 차이 3성분을 두 번째 충격기동으로 산출합니다. 위치와 속도를 기동 없이 강제로 일치시키지 않습니다.
6. 수렴한 초기 속도로 더 엄격한 적응형 적분을 새로 실행합니다. 이 재전파 상태가 최종 궤적이며 위치 오차·수치 차이·Jacobi 변화·달 충돌 여유·LLO 원궤도 요소를 검사합니다.

알고리즘은 변분방정식을 사용하는 single shooting입니다. Multiple shooting, 중간 보정 기동, multi-revolution Lambert 분기, 연속 최적 제어는 구현하지 않았습니다. 기동 후 임의 가속도나 경로 보정 항을 추가하지 않습니다.

## 한계와 후보 선택

기본 후보 탐색 순서는 짧은 비행 시간부터 시작하고, 같은 시간에서는 가까운 NRHO 위상을 먼저 시험합니다. 원월점 이탈만 강제하지 않습니다. 모든 후보는 각자의 JPL 기준 출발 위치와 속도를 갖습니다.

- 최소 ΔV: 적격 후보 중 `|Δv_departure|+|Δv_insertion|`가 작은 값을 선택합니다.
- 최소 시간: 먼저 더 짧은 전이 시간을 선택하고 같은 시간에서는 ΔV로 비교합니다.
- Balanced: `ΔV[m/s] + 100*비행시간[day]`라는 공개한 경험적 가중 점수로 비교합니다. 가중치는 NASA 임무 기준이 아닙니다.

기본 최대 shooting 반복 수는 후보당 20회이고 기본 전체 임무 계산 한도는 60초입니다. 적분 단계마다 시간 예산을 검사하며 후보 사이에 Worker 이벤트 처리를 허용합니다. UI 취소는 Worker를 종료합니다. 직접 계산 API도 취소 콜백을 지원합니다. 시간 한도 전에 완전히 검증한 후보가 있으면 그중 최선의 결과와 `timed_out=true`를 반환할 수 있고, 없다면 `TRANSFER NOT CONVERGED`입니다.

수렴 실패·ΔV 초과·충돌·부정확한 원궤도 진입은 성공 경로로 반환하지 않습니다. 후보 목록에 진단값과 실패 원인을 보존합니다. 유한한 초기 추정 탐색이므로 실패가 물리적 불가능의 증명이 아니며, 성공해도 전역 최소 ΔV 또는 전역 최소 시간을 보증하지 않습니다.

## 수치·충돌·LLO 검사

Shooting의 기본 적분은 `rtol=8e-11`, `atol=2e-13`입니다. 최종 재전파는 `rtol=2e-12`, `atol=1e-14`, 최대 간격 0.003 TU를 사용합니다. 기본 전이 API 위치 허용값은 5 m이나 통합 임무는 **0.01 m**로 더 엄격하게 요청합니다. 이는 계산 연결 기준이며 실제 데이터·항법 정확도 주장이 아닙니다.

검사 항목:

- 실제 재전파 최종 위치가 목표 허용오차 이내인지
- LLOI ΔV 적용 후 목표 속도, 궤도면, 궤도 위상이 맞는지
- 달 중심 순간 관성 상태의 LLO 이심률이 작은지
- 두 기동의 총 ΔV가 사용자 한계 이내인지
- 각 무추력 구간의 Jacobi 변화가 작고, 엄격한 재전파가 shooting 결과와 일치하는지
- 달 충돌 포락면과 지구 표면을 피하는지

전이의 달 충돌 포락면은 `max(LOLA 반지름 1737.4km, JPL 반지름)+12km`입니다. 고도 100 km로 들어오는 전이에 대한 보수적 구형 모델 검사이며 지역 지형 인증이 아닙니다. 채택된 적응형 상태를 검사하고 한 간격의 이동을 달 중심 거리의 약 3% 이하로 제한하지만, 연속 시간의 엄밀한 충돌 불가능 증명은 제공하지 않습니다. LLO 이후에는 기존 실제 LOLA 지형 검사를 다시 적용합니다.

## 실제 실행 결과

선택된 JPL row 42와 Mode A에서 다시 계산한 Connecting Ridge 착륙의 LLO 초기상태를 사용했습니다. 기본 자동 탐색 120개 후보를 약 19.86초 동안 실행했고 37개 후보가 전이 검사를 통과했습니다. 같은 머신이라도 브라우저·부하에 따라 시간은 달라집니다.

| 항목 | 실제 결과 |
|---|---:|
| 선택 출발 위상 | 1/12 주기, 30° |
| 비행 시간 | 259,200 s, 3일 |
| NRHO 이탈 ΔV | 134.093195 m/s |
| LLO 진입 ΔV | 678.434926 m/s |
| 전이 총 ΔV | 812.528121 m/s |
| 실제 도착 위치 잔차 | 약 0.0000452 m |
| LLOI 후 회전좌표계 속도 잔차 | 계산 정밀도 내 0 |
| 더 엄격한 전파와의 위치 차이 | 약 0.0000262 m |
| 전이 Jacobi 최대 변화 | 약 6.37×10⁻¹³ |

이 수치는 상대시간 CR3BP 기준 임무의 계산 결과입니다. NASA가 계산하거나 검증한 이탈·진입 ΔV가 아닙니다.

독립 Python/SciPy DOP853 검증은 저장된 기동 후 상태에서의 전이뿐 아니라 **원본 JPL 초기상태 → 선택 위상 → 출발 기동 → 전이**를 다시 전파했습니다. 후자의 목표 위치 잔차는 약 0.000118 m, 전이 Jacobi 변화는 약 5.56×10⁻¹³였으며 뒤따르는 착륙 재전파도 통과했습니다. 저장된 기동 후 상태에서 시작한 DOP853과 TypeScript 전이 끝 위치 차이는 약 0.00000135 m입니다. 결과는 `docs/nrho-independent-validation.json`에 있습니다.

## 착륙 구간 연결 및 연료

통합 모듈 `mission.ts`는 실제 도착 위치를 그대로 유지하고, 산출한 LLOI 속도 기동을 적용한 뒤 주차 궤도·DOI·기존 24개 동력 하강 제어를 다시 전방 적분합니다. 최종 지형·위치·속도·연료·추력 검사는 이 재전파 결과에 다시 수행합니다. 원래의 검증된 착륙 경로를 시각적 선분으로 이어 붙이는 방식이 아닙니다.

각 충격기동에서 `m_after=m_before*exp(-ΔV/(Isp*g0))`를 적용합니다. 사용자가 **LLO 질량**을 지정한 경우 필요한 NRHO 출발 질량을 역산해 표시합니다. **NRHO 질량**을 지정한 경우에는 실제 기동 소모 뒤의 LLO 질량으로 착륙 제어를 다시 계산하고 전이·착륙 질량을 최대 세 차례 결합합니다. 탱크 용량·실제 엔진 운용 제약은 별도 모델이 없으므로 역산 질량을 실제 비행체 능력으로 해석하면 안 됩니다.

실제 통합 기본 사례는 LLO 질량 1,500 kg에 대해 NRHO 출발 질량 약 1,943.298 kg, 전체 ΔV 약 2,569.949 m/s, 최종 착륙 위치 잔차 약 0.000180 m, 접지 속도 약 0.5000004 m/s로 구간별 모델 검사를 통과했습니다. 상세한 실제 결과는 `docs/nrho-validation-results.json`에 있습니다.

한 바퀴 LLO 주차를 추가한 별도 실행에서는 동일한 30° 출발 위상의 shooting이 수렴하지 않았습니다. 3일 비행 시간에 12개 위상을 재탐색한 24개 후보 중 5개가 전이 검사를 통과했고, 선택 위상은 0°였습니다. 이 경우 전이 ΔV는 약 816.820 m/s, 주차 뒤 착륙 시작 위치 잔차는 약 0.0000338 m, 최종 착륙 위치 잔차는 약 0.0000127 m였습니다. 주차 시간을 바꾸면 도착 좌표계의 위상도 바뀌므로 이전 출발 위상의 성공을 보장하지 않습니다.
