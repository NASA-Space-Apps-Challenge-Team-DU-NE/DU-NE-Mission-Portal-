## 실패 경고 및 해결 방법 안내 — Mode B 이전 기록

실패 원인 진단 테스트 10개를 추가하여 `npm test` **35개 전체 통과**, `npm run build` 통과를 확인했습니다. 추력·추진제·최소 추력, 중첩 NRHO 착륙 진단, 시간 초과·ΔV 한도, 지형·접지 검증, 입력·데이터 오류, 성공·취소 시 경고 제외를 검사합니다. 최종 경로와 무관하게 탈락한 다른 후보의 제약 위반이나 검증에 성공한 전이의 시간 제한 알림을 실패 원인으로 잘못 표시하지 않습니다.

기존 적분과 최적화 알고리즘은 유지했습니다. 진단을 위해 LLO 후보의 `min_thrust_n`을 추가하고 NRHO 착륙 실패의 원래 입력·상태·후보 목록을 전달합니다. 기존 두 LLO 결과의 수치 일치 회귀 테스트도 통과했습니다.

Chrome에서 실제 Worker 계산으로 최대 추력 100 N의 실패 경고, 위도 0°의 지형 범위 경고, 건조 질량 2,000 kg의 입력 오류, NRHO 계산 시간 1초의 시간 초과 경고를 확인했습니다. Escape 닫기·원인/해결 방법 다시 열기·설정으로 복귀·사용자 취소 후 경고 없음도 확인했습니다. 화면 증거: `docs/screenshot-failure-warning.jpg`.

## 재현 명령

프로젝트 루트에서:


## 기존 LLO 독립 적분기 대조

선택적 개발용 `scripts/independent_verify.py`가 출력된 초기 상태와 24개 추력 제어 구간을 **SciPy DOP853**로 다시 적분했습니다. 실제 원본 SPICE 커널의 `sxform`으로 최종 위치와 속도를 MOON_ME로 변환했습니다. 23,956회의 독립 RHS 평가를 사용했습니다.

- TypeScript 대비 최종 위치 차이: 약 **0.00000185 m**.
- 최종 속도 차이: 약 **1.7×10⁻⁹ m/s**.
- 최종 질량 차이: 약 **4.1×10⁻¹² kg**.
- 원본 SPICE로 변환한 목표 위치 잔차: 약 **0.0000238 m**.
- 원본 SPICE로 변환한 표면 상대 접지 속도: **0.50000025 m/s**.

이는 서로 다른 적분 구현이 같은 모델을 풀고 있음을 확인합니다. 실제 임무 모델의 완전성은 보증하지 않습니다. 원시 결과는 `docs/independent-validation.json`에 있습니다.
