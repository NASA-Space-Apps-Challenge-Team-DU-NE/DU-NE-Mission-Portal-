Explore the code behind the Lunar Landing Site Navigator and see how it compares candidate landing sites and dates.

What the code does

  • Uses lunar terrain data to assess the ground and local horizon around candidate landing sites.
  • Compares the positions of the Sun and Earth with the local horizon to estimate sunlight and Earth visibility for a selected site and time.
