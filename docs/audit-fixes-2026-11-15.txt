검증 해석과 남은 범위
전체 고해상도 원시 DEM/과학 자료로 모든 파이프라인을 새로 생성한 것은 아니다. 출하 데이터 검사, 실제 소규모 SPICE 대조, 경계 조건을 재현하는 테스트를 함께 사용했다.
과거 illumination/masks/layers_minerals/mast/wueller/ephemeris_spice 보고서는 당시 전체 입력 해시가 없어 재현 완료를 주장할 수 없다. 원본을 validation/history에 보존하고 REFERENCE_ONLY 및 추적 한계를 화면에 표시했다. 새 실행부터 실제 입력 해시를 기록한다.
기존 과학 모델의 물리 정확도, 마스크 차이의 허용 기준, mast/Wueller 결과의 과학적 합격을 보증하는 보고서는 아니다. 기존 제한·검토 필요 품질을 유지한다.
캐시 입력 식별은 기존의 경로·크기·수정시각 방식이다. 파일 크기와 수정시각까지 의도적으로 동일하게 유지한 원본 교체는 자동 검출 범위 밖이다. 산출물 무결성은 SHA-256으로 검사한다.
초기 브라우저 실행의5초 준비 대기 초과와 한 차례 Chrome 프로세스 중단은 통과로 세지 않았다. 대기 기준을20초로 두고 직렬 재실행한11개 전체가 통과했다. 마지막 Horizons 이름 호환 보완은 추가 단위 테스트와 전체 타입·린트·125개 테스트/빌드로 검증했다.

항목별 수정과 증거
R01 [수정 완료] 빛 릴레이가 임무보다 긴 동시 암흑 시간을 계산함
  수정: 종료 표본을 0시간으로 처리하고 실제 구간 길이로 적분.
  확인: 240시간 임무의 공동 암흑=240시간. 짧은 마지막 구간·종료 순간 밝음 검증.

R02 [수정 완료] 1년 기지 운용에서 정전 시작과 가동률을 잘못 계산함
  수정: 소비 전 SOC를 기록하고 배터리 고갈 시점에서 가동·정전 시간을 분리.
  확인: 0.8kWh/1kW/2시간 → 가동률40%, 정전1.2시간, 정전 시작0.8시간.

R03 [수정 완료] 30일 자동 전력 설계가 719시간만 사용함
  수정: 첫 30일 전력 설계에 720시간 종료 표본까지 포함.
  확인: 실제 Worker handler 테스트에서 719~720시간의 발전을 반영하고 720시간 이후는 제외.

R04 [수정 완료] 하루 최소 교신에서 마지막 이동 구간을 빠뜨림
  수정: 마지막 24시간 이동 창 및 창 양 끝의 모든 표본 경계를 비교.
  확인: 24.5시간 사례의 최소 교신21.5시간. 불규칙 표본32패턴을 독립 교집합 계산과 비교.

R05 [수정 완료] 오류 뒤 새 Worker에 격자를 다시 초기화하지 않음
  수정: Worker 재생성 시 init을 재전송. 중계·쌍둥이 요청 전 마지막 score도 복원. 재시도 버튼 제공.
  확인: 단위4개와 Chrome에서 실행 중 오류/첫 스크립트 로딩 실패 뒤 복구 확인.

R06 [수정 완료] 유효하지 않은 천체력·격자 구조를 정상 데이터로 받아들임
  수정: 천체력·격자·카탈로그·배포 목록의 내부 구조, 길이, 유한 수치, 좌표·품질·enum 검사.
  확인: 어댑터38개. 24개 실제 레이어 및 정상 null 호환, 잘못된 count/nx/바이너리/manifest 거부.

R07 [수정 완료] 레이어 목록 전체가 없어도 정상 상태와 순위를 표시함
  수정: layers.json 실패 사유를 저장하고 degraded 상태와 계산에서 빠진 기준을 표시.
  확인: Chrome 404 주입 시 일부 자료 없음/실패 경로 표시. 정상 준비 상태로 표시되지 않음.

R08 [수정 완료] 새 검증 표의 잘못된 한 행이 앱 전체를 오류 화면으로 바꿈
  수정: 검증 표 행을 읽을 때 검증하고 카드별 오류 경계로 격리.
  확인: Chrome null 행 주입 시 해당 카드만 자료 없음, 다른 화면 전환 정상, pageerror 없음.

R09 [수정 완료] 완료 캐시가 중간 산출물 삭제를 발견하지 못함
  수정: 완료 캐시에 out/build 산출물과 보존 파일의 크기·SHA-256 기록.
  확인: 중간 terrain/meta.json 또는 보존 그림 삭제 시 다시 실행. 정상 캐시는 유지.

R10 [수정 완료] 국지 지형 단계가 DEM 타일 변경 후에도 이전 결과를 재사용함
  수정: VRT가 실제로 참조하는 중첩 타일과 대체 DEM80 입력을 캐시 의존성에 포함.
  확인: VRT를 그대로 두고 타일 변경 시 결과1→2 재계산. DEM80 변경도 무효화.

R11 [수정 완료] 완전성 검사가 빈 과학 데이터와 금지 품질 레이어를 통과시킴
  수정: 빈 필수 payload, 필수 레이어 누락, 금지 품질, 잘못된 참조·크기·coverage 차단.
  확인: 손상14종 거부. 최종 배포166파일 complete_ok=true, problems=[].

R12 [수정 완료] 모든 DEM 칸이 결측이어도 빈 격자를 성공으로 저장함
  수정: DEM 유효 칸이0개면 격자를 배포하지 않고 실패 반환.
  확인: 모두 결측인 합성 DEM에서 exit1, 격자 manifest/완료 stamp 없음.

R13 [수정 완료] LP TiO₂에 2° 행이 없으면 전체 레이어 생성이 중단됨
  수정: LP TiO₂에2° 행이 없으면 선택 레이어를 NO_DATA로 기록하고 다른 계산 계속.
  확인: 5° 행만 있는 입력에서 예외 없이 빈 선택 레이어. 다른 해상도로 임의 대체하지 않음.

R14 [수정 완료] 일부 출처 라벨과 재현 메타데이터가 실제 계산을 추적하지 못함
  수정: 계산 표본에 따라 SPICE/Horizons/근사를 표시. 검증 입력 해시·좌표계 기록 및 과거 결과 구분.
  확인: 187개 CRS를 원본 SHA 일치로 보완. 실제 프레임1건·천체력16건 통과. 과거6개는 원본 보존/REFERENCE_ONLY.

R15 [수정 완료] 기지 부하에 음수를 입력하면 전원 없이 가동률 100%가 됨
  수정: 유한한 비음수 부하·용량과 유효 비율/임계 순서만 허용. UI·Worker·계산 함수 모두 검사.
  확인: 음수/NaN/Infinity/누락 값 거부. Chrome 음수 입력 실행 차단 후 정상 입력의1년 계산 완료.

R16 [수정 완료] 교신·착륙 구간 표의 종료 시각과 지속시간이 불일치함
  수정: 교신·착륙 표에서 공통 반열린 시간 구간 계산 사용.
  확인: 불규칙 표본에서도 끝−시작=지속시간. 종료 순간만 참인 표본은 구간 생성 안 함.
