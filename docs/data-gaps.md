# 부족한 데이터 정리

작성: 2026-11-14 (KST). 대상: LUNA-NAV 기능 목록 v2 전체를 남극 75°S 이남에서 돌릴 때, 그리고 달 전역으로 넓힐 때.

근거:
- 로컬 사본 `NASA_Data\DU_NE Data` 의 실제 파일 (Drive 원본 2,083개와 MD5 일치 확인)
- 팀 보고서 `Catalogs/NASA_Data_Gaps_2026-11-14/UNAVAILABLE_DATA.md`, `Workspace/Global_Data_2026-11-14/MISSING_DATA_REPORT.md`, `DEVELOPER_DATA_INTEGRATION_GUIDE.md`
- 파이프라인 산출물 `web/public/data` (2026-11-14 재생성: 착륙지 27곳 중 확인 3곳, 지상국 4곳 중 여주 미검증, 착륙선 프리셋 품질 REFERENCE_ONLY)

상태 표기:
- **없음**: NASA_Data 에 해당 자료가 없다. 새로 구해야 한다.
- **부분**: 일부 지역·일부 변수만 있다.
- **미대조**: 자료는 받아 두었지만 카탈로그·계산에 아직 반영하지 않았다.
- **공개 자료 없음**: 팀 조사에서 공개된 검증 가능한 자료를 찾지 못했다. 기능은 경고·가정값·"자료 없음" 표시로 처리한다.

## 4. 요약

- **바로 만들 수 있음**: 전역 고도·경사·온도·원소·수소·자기장·지질·크레이터·레이더 레이어 (3절).
- **새로 구해야 함**: 북극 극지 DEM·조명 지도, 전역 단층애·낙석 목록, 고해상도 FeO·TiO₂ 지도, Diviner GCP 추가 밴드 (2절).
- **대조만 하면 됨**: 여주 지상국 좌표, 착륙선 제원, 착륙지 대표 좌표, 과거 미션 이벤트 시각 (1절).
- **공개 자료로 채울 수 없음**: 남극 분사 먼지 실측, 수 m 급 전역 장애물, 직접 수빙량, 아르테미스 후보 경계. 경고·가정값·"자료 없음"으로 표시한다.
