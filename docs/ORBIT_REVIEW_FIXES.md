# Orbit 검토 수정 · 언어 동기화 · 보고서 연결

2026-11-15 · `integration/orbit-local` · 아래는 로컬 검증 기록이다. 이후 GitHub 반영은 [게시 기록](ORBIT_GITHUB_HANDOFF.md)을 따른다.

## 변경 사항

1. **착륙지 카탈로그 유지.** 비교 후보 적용·검증 예제·임무 JSON 복원 시 카탈로그 ID를 유지해 전용 지평선 마스크가 좌표 격자로 바뀌지 않도록 수정했다. JSON의 선택적 `site_ref`에 catalog/cell/custom 구분을 저장한다. 이전 좌표 전용 파일은 정확히 일치하는 유일한 카탈로그 항목만 복원한다. 근처 지점으로 좌표를 이동하거나 중복 항목을 추측하지 않는다. 명시된 ID와 현재 자료의 좌표가 다르면 전체 적용을 거부한다.
2. **초기 연결 실패 복구.** 포탈의 메타데이터를 공유 상태로 관리하고 05의 다시 연결에서 다시 요청한다. 이전 요청의 늦은 오류가 새 성공 상태를 덮어쓰지 않는다. 전체 페이지를 새로고침할 필요가 없다.
3. **Esc 도움말 닫기.** 05에서도 포탈 도움말을 Esc로 닫는다. Orbit 탭에서 포탈 시간 재생 단축키를 막는 기존 동작은 유지한다.
4. **영어/한국어 동기화.** 포탈 EN/KR 선택을 같은 origin의 검증된 브리지로 임베드 Orbit에 전달한다. 언어 전환으로 iframe을 다시 만들지 않으므로 진행 중 Worker와 완료 결과를 유지한다. 조작·상태·검증 설명·오류 및 해결 안내 등 502개 번역 항목을 추가했다. 기존 포탈 번역을 우선해 단어 일부가 섞이지 않게 한다. 원본 결과 객체·JSON·코드 진단은 번역하지 않으며, 독립 Orbit 진입점은 기존 동작을 유지한다.
5. **보고서와 순위 CSV.** 보고서는 현재 Orbit 입력, 계산 상태, ΔV·추진제·착륙 잔차·접지 속도, 검증 상세, 빌드 및 자료 식별자를 포함한다. 순위 CSV는 기존 8개 열과 점수/순서를 유지하고 `row_type`과 `orbit_*` 열을 추가한다. 현재 임무는 순위와 점수를 비운 `current_plan` 행에 포함한다.

## 결과를 연결하는 기준

- 계산 당시 전체 입력과 현재 행의 입력이 정확히 일치하고 빌드 ID도 같아야 결과 수치를 출력한다. 반올림한 화면 좌표로 비교하지 않는다.
- 다른 후보를 자동으로 계산하지 않는다. 계산하지 않은 후보는 `NOT_CALCULATED`이며 수치 칸을 비운다.
- 실행 중·취소·입력 변경·빌드 불일치·자료 누락은 상태로 구분한다. 실패 결과를 성공으로 바꾸지 않는다.
- `VALIDATED` 결과는 기존 필수 검사 존재/통과와 실제 경로 확인을 그대로 사용한다. 순위는 기존 표면 평가 점수이며 Orbit 결과를 넣어 점수를 다시 만들지 않는다.
- CSV의 열 이름과 상태 코드는 안정적인 영문 식별자다. 설명 보고서는 선택 언어를 따르고 원본 진단 JSON은 보존한다.

## 검증

최종 실행 기록: [검증 JSON](orbit-review-fixes-validation.json), [실제 기본 임무 요약](orbit-review-fixes-browser-default.json). 화면: [영어](ui/orbit-review-english.png), [한국어](ui/orbit-review-korean.png).

- `npm test`: 포탈 타입 검사·규칙 검사·단위 검사 170개, 기존 Orbit 회귀 검사 76개 통과.
- Chrome 통합 11개 통과: 실제 기본 임무, 1월 미수렴, 취소/탭 이동, GRAIL 누락, 입력 검증, 모바일, 카탈로그 복원, 초기 503 복구, Esc, 영어 실패 안내, 기존 9개 탭.
- 기본 임무의 계산 도중 언어를 바꾸고 완료 후 다시 한국어로 전환해도 같은 iframe과 결과를 유지함을 검사했다. `VALIDATED` 및 20/20 필수 검사 통과를 확인하고 상단 보고서·순위 CSV를 실제로 내려받아 검사했다.
- 카탈로그 후보·예제·새 JSON·이전 JSON을 적용한 뒤 표면 평가 KPI와 전용 지형 표시가 적용 전과 같은지 검사했다.
- 번역 우선순위의 마지막 수정 후 관련 성공/실패/탭 3개 사례를 다시 실행해 모두 통과했다. 기본 임무 경로 샘플은 6,653개였다.
- 물리·Worker·서비스·포탈 평가/어댑터·양쪽 정적 과학 자료 510개 파일은 수정 전 SHA-256과 일치한다. 원본 별도 Orbit 체크아웃도 기존 변경 상태를 유지했다.

첫 브라우저 실행에서 실제 `<b>` 요소를 heading으로 찾던 테스트 선택자가 실패해 수정했다. 검증 중 확인한 번역 충돌은 기존 포탈 문구를 우선하도록 수정하고 회귀 검사를 추가했다. 테스트를 맞추기 위해 계산식·허용오차·성공 조건을 바꾸지 않았다.

## 검증 범위

이번 검사는 통합·UI·내보내기 회귀 검사다. 새 물리 모델 검증 캠페인이나 모든 날짜/착륙지의 비행 가능성 검증은 아니다. `VALIDATED`의 의미도 기존 시연용 모델 검사 통과로 동일하다. 배포물은 `web/dist`이며 Python/Node API 서버와 DB 없이 정적 호스팅으로 동작한다.
