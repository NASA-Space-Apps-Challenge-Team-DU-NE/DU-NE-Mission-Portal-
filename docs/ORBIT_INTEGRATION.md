# 포탈 + Orbit 로컬 통합

2026-11-15. 포탈 `ed8146bf3f91f0067f630cc4af9df31ba079d18a`에서 로컬 브랜치 `integration/orbit-local`을 만들었다. Orbit `7d69425493ede243ddd79ab2c87a6169e52c07bf`의 추적 파일 421개(약 59.3 MB)를 `orbit/`에 포함했다. 다른 체크아웃에 있는 개인 경로 설정·복구 메모는 포함하지 않았다. 최초 검증은 로컬에서 진행했으며, 이후 사용자 요청에 따른 GitHub 반영 절차는 [게시 기록](ORBIT_GITHUB_HANDOFF.md)에 정리했다.

## 사용자가 선택한 통합 방식

- 05에서는 포탈 오른쪽 달/현장 뷰를 unmount하고 Orbit 화면을 넓게 사용한다. 다른 탭의 레이아웃은 유지한다.
- 기본 임무 전체를 Orbit 검증 예제로 변경한다. 목표는 Connecting Ridge 좌표 −89.4441°, −137.291°, 2026-11-16 00:00 UTC다. 질량 기준 LLO, 총질량 1500 kg, 건조 650 kg, 최대/최소 추력 12000/0 N, Isp 320 s, GRAIL 30차, 전이 3일, 하강 880초, 접근 방향 180°다.
- 전력·통신 프리셋은 별도다. 궤도 예제의 모델 검증 통과가 표면 운용 요구 조건까지 통과한다는 의미는 아니다.

## 구조와 실행

포탈은 계획 입력을 소유하고 `/orbit/index.html?embed=portal`을 iframe으로 연다. 별도 번들로 CSS·Three 버전을 격리한다. Orbit은 `CONFIG_ACCEPTED` 이후 명시적인 실행 요청이 있을 때만 자기 Worker에서 계산한다. 계산 API 서버는 없다.

루트 `npm install`은 `web`과 `orbit/frontend`의 잠금 파일로 의존성을 설치한다. `npm run dev`는 Orbit 정적 산출물을 생성한 뒤 포탈 Vite를 5175에서 실행한다. `npm run build`의 최종 배포 디렉터리는 `web/dist`다. `web/public/orbit`는 생성물이며, 각 소스/데이터가 저장소 안에 있어 별도 개인 PC 경로가 필요하지 않다.

`prepare-orbit.mjs`는 실제 천체력 기간, 자료 SHA-256, 검증 항목, 기본 예제를 경량 메타데이터로 생성하고 Orbit을 빌드한다. 코드에 포함된 빌드 ID와 서버 메타데이터가 다르면 연결을 거부한다. 기존 단일 13.16 MB 천체력 팩은 그대로이며 메타데이터 파일은 이를 대체하는 궤도 표가 아니다.

## 입력과 상태

- 계획 좌표는 `useResolvedSite()`, 시간은 `landing`, 추진 값은 `landerExtra`, 나머지 궤도 값은 `orbitSettings`에서 구성한다.
- `viewRef`, `viewLanding`, 재생 시각 `t`는 궤도 입력에 들어가지 않는다.
- 총질량은 건조+추진제 한 번만 합산한다. 최소 추력, 질량 기준, GRAIL 차수, 전이/하강/접근/허용오차/계산 제한을 01에서 편집한다.
- ISO UTC는 밀리초를 보존한다. 날짜를 다른 표의 시작 시점으로 자동 보정하던 포탈 초기화 경로는 제거했다.
- 자동 하강 시간/방향은 필드 생략이며 null/0으로 대체하지 않는다. Mode A 요청, 범위 밖 값, 비유한 숫자, 필수값 누락을 거부한다.
- 01의 임무 JSON은 전체 Config와 스키마, 선택적 `site_ref`를 보존한다. 비교 후보·검증 예제·JSON 복원 시 카탈로그 ID와 전용 지형 마스크를 유지한다. 이전 좌표 전용 파일은 정확히 일치하는 유일한 카탈로그만 복원하고, 가까운 지점으로 이동시키지 않는다. 명시된 식별자와 좌표가 다르면 입력을 거부한다. 05의 결과 JSON은 입력·빌드·자료 메타데이터·원래 계산 결과를 보존한다.
- 비교 후보 생성 시 유효한 궤도 입력 스냅샷을 함께 저장한다. 이전 후보에 입력이 없으면 명시적으로 표시하며, 현재의 다른 임무 궤도 결과를 붙이지 않는다. 09에는 현재 계획의 궤도 검증을 별도로 표시한다.

메시지 계약은 `dune-orbit-bridge.v1`이며 source/origin/session/revision/requestId와 정규화한 Config의 정확한 문자열 식별자 `inputKey`를 검사한다. `inputKey`는 SHA가 아니라 동일 입력 비교용이다. 같은 origin의 iframe만 지원하며 `*` origin이나 입력에서 받은 임의 자산 URL을 사용하지 않는다. 실행 중 입력 변경, 취소, 탭 이동으로 iframe이 없어지면 실제 Worker를 종료한다. 포탈 언어 변경은 `SET_LANGUAGE` 메시지로 전달하고 iframe을 유지하므로 진행 중 계산과 완료 결과를 보존한다. 이전 요청의 완료/진행 응답은 무시한다.

## 지원 범위와 물리 기준

Mode B 착륙 UTC는 2026-11-01 ~ 2027-01-31 마지막 밀리초다. 환경/참조 데이터의 2026-10-16 ~ 2027-02-01은 전체 비행에 필요한 앞뒤 여유이며 착륙 선택 범위가 아니다. 정밀 착륙은 남위 75–90° LOLA 240 m 지역이다. 포탈의 북극/전역 지도 지원과 Orbit의 착륙 지형 지원은 별개다.

Orbit의 수치 물리 코드·NASA 데이터·고정 종말 정책은 수정하지 않았다. 전체 임무 후보 평가, 유한 연소, 연료 소모, GRAIL, 접촉/저고도 속도/추력 기울기 제한을 유지한다. 임베드 UI도 3D 경로를 계산 결과에서만 만든다.

`VALIDATED`는 결과 상태와 모든 필수 물리 검사 존재/통과를 함께 확인한다. 빈 검증 객체나 단순 수치 수렴은 성공이 아니다. 미수렴·자료 누락·계산 취소는 성공 경로로 바꾸지 않는다. NASA 자료 사용이나 작은 수치 잔차는 실제 임무 안전·운용 인증이 아니다.

## 최초 통합 검증

아래는 검토 수정 전의 통합 기록이다. 후속 수정·번역·내보내기 검증은 [검토 수정 기록](ORBIT_REVIEW_FIXES.md)을 따른다.

검증 기록: [통합 검증 JSON](orbit-integration-validation.json), [실제 기본 임무 결과](orbit-integration-browser-default.json), [하위 경로 검사](orbit-integration-subpath.json).

- 포탈 타입·규칙 검사와 단위 테스트 150개, 기존 Orbit 테스트 76개 통과.
- Chrome 통합 사례 6개와 기존 9개 탭 smoke 검사 통과. 첫 실행의 2개 경고창 검사에서 테스트의 `dialog` 선택자를 실제 `alertdialog`로 수정한 후 두 사례를 재검사했다.
- 기본 임무는 실제 Worker 계산에서 `VALIDATED`, 20/20 물리 검사 통과, 경로 샘플 6653개. 1월 대표 사례의 미수렴과 GRAIL 누락은 빈 경로와 경고를 유지한다.
- 루트 `npm install`, `npm run build`, `npm run dev` 확인. 정적 하위 경로 `/mission-portal/`에서도 연결·Worker·천체력 로딩 확인.
- 원본 대비 물리 코드 19개, Worker 1개, 정적 NASA 자산 213개, 기존 테스트 21개 파일의 바이트가 모두 일치한다.

다른 기존 브라우저 검사 모음과 전체 독립 물리 검증 캠페인은 이번 통합에서 재실행하지 않았다. 단독 Orbit의 과거 보고서는 `orbit/docs`에 남아 있으며 이 통합의 검증과 구별한다.

## 유지보수

Orbit UI/브리지 변경 후 루트 `npm run prepare:orbit`로 정적 iframe 산출물을 갱신한다. 물리 코드를 변경할 경우 `orbit/tests`와 독립 물리 검증의 적용 범위를 다시 검토한다. 현재 100 km LLO 단독 기능은 Orbit 단독 진입점에 남아 있고 포탈 연결은 Mode B NRHO만 허용한다. 05를 떠나면 실행은 취소되며 완료 요약을 제외한 3D는 다시 계산해야 한다.

포탈의 영어/한국어 선택을 임베드 Orbit에 동기화한다. Orbit 조작·상태·물리 설명·오류 및 해결 안내에 502개 번역 항목을 추가했다. 원본 결과 객체와 JSON·코드 진단은 번역하지 않아 수치·식별자·출처를 보존한다. 독립 Orbit 진입점에는 이 임베드 전용 번역기를 적용하지 않는다.

상단 보고서는 현재 임무의 Orbit 입력·상태·추진제·ΔV·착륙 잔차·검증 상세·빌드/자료 식별자를 포함한다. 순위 CSV는 기존 점수/순서를 유지하며, 입력이 정확히 일치한 계산 결과만 연결한다. 미계산 후보는 `NOT_CALCULATED`이고 현재 임무는 순위/점수를 비워 둔 `current_plan` 행으로 별도 포함한다. 메타데이터 일시 오류는 05의 다시 연결에서 공유 상태를 갱신해 복구한다.
